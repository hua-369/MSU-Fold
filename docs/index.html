MSU-Fold: Unified Multi-Scale Heatmap Decoding and Language-Grounded Skill Decomposition for Multi-Step Robotic Cloth Folding

Code · github.com/hua-369/MSU-Fold
⭐ Code 🚀 Getting started

One natural-language instruction in, a folded garment out. A single shared pick/place heatmap head serves both one-arm and two-arm steps, a multi-scale adapter fuses hidden states of a frozen ViT, and a skill library decomposes the instruction into executable folding steps that run closed-loop in simulation and on a real dual-arm robot.
